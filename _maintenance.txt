Before publication:
- Read _content-review.json for sources and outstanding direct checks.
- Verify changed hours, prices and closure notices with the venue or official source.
- Keep dated facts distinct from current promises. Do not change a review date solely to appear fresh.
- Update visible copy, search/social descriptions and JSON-LD together.
- Update sitemap lastmod only for pages that substantively changed.
- Run python3 _seo_check.py and git -c core.whitespace=cr-at-eol diff --check.
- Preview the affected pages at localhost:8000, then push through the existing GitHub Pages workflow.

- Routes: a web review is not a physical access survey; verify paths and accessibility before claiming them.

Hosting observations:
Cloudflare supplies a managed robots.txt that differs from this repository. Its public rules permit Googlebot, and Search Console reads the submitted sitemap successfully. Restore the Sitemap declaration and intended exclusions at the hosting layer if the owner changes that configuration. Do not disable bot protections without verified Googlebot failure evidence.
Public mailto links use Cloudflare's documented email_off comments to avoid broken email-protection links. Check the served HTML after deployment.
The template has a noindex tag as an additional safeguard. Do not copy that tag into a public page.
No real-user Core Web Vitals or Lighthouse grade is asserted by the source checks.
